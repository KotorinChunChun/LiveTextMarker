# LiveTextMarker

Windows 10 / 11（64 bit）用。ポインタの位置にある文章を認識し、折り返しを含む各表示行を下線または薄い塗りで強調します。現行版は **1.1.0** です。

## 起動と操作

1. 配布フォルダーをすべて展開し、`app/LiveTextMarker.exe` を起動します。
2. 既定では、文字の上で **Ctrlを押している間だけ**強調します。開始ボタンを押す必要はありません。
3. 常時表示を使う場合は「開始 / Start」または開始キーを使います。「一時停止 / Pause」で常時表示を停止します。

Ctrl押下での実行と常時表示は独立しています。一時停止中でもCtrlを押すと表示し、離すと消えます。常時表示中はCtrlを離しても表示を続けます。「Ctrl押下で実行」をオフにすると、Ctrlだけでの実行を無効にできます。

- 開始／一時停止キーの既定：Ctrl + Alt + U
- アプリ終了キーの既定：Ctrl + Alt + Q
- 設定画面のタイトル：`設定 - LiveTextMarker - ver 1.1.0`
- ×または「通知領域へ」：設定画面をトレイへ格納します。認識機能は停止しません。
- トレイアイコンのダブルクリックまたは「設定を表示」：設定画面を戻します。
- 右下またはトレイメニューの「アプリを終了させる」：アプリを終了します。

## 設定

開始／一時停止とアプリ終了のキーは、それぞれCtrl／Alt／Shift／Winのチェックボックスと最後のキーのコンボボックスを横並びで指定します。「なし」とキー一覧から選択でき、修飾キーのみの割り当てにも対応します。すべて未選択で「なし」の場合は割り当てなしです。同じ割り当てを両方に指定すると両方を無効化し、重複を表示します。他アプリとの競合などで登録できないキーも画面に表示します。

- 表示方法：下線／塗り。下線と塗りの色は別々に保持します。
- 下線の太さ：1～12（96 DPI基準）。DPIに応じた整数ピクセルで各行の太さを統一します。
- 上下位置：-30.0～30.0、既定-2.0。負で上、正で下へ移動します。境界付近では線を細くせず、全体が境界内へ収まる位置に調整します。
- 塗り：既定は黄色、濃さ16%。8～30%で文字の読みやすさを調整します。塗りでは太さ・上下位置は使いません。
- OCR：文字情報を取得できない画像などをローカルで認識します。既定でオンです。
- Ctrl押下で実行：既定でオンです。保存済みの選択は引き継ぎます。

設定変更はその都度保存し、再起動後も保持します。常時表示の開始状態は保持せず、起動時は一時停止です。現在の検出方式と行数、直近10件のログを表示します。ログには画像や本文を記録せず、終了時に破棄します。

## 認識範囲

UI Automation（UIA）のTextPatternから段落を取得し、同じ表示行の文字断片を結合します。文字を取得できない場合は、UIAから取得した対象要素の範囲内だけを撮影し、同梱のTesseractで日本語・英語の横書きを認識します。

本文・ボタン・リンク・タブ見出し・文書・ペインなど、ポインタ配下の最寄りの要素を境界として使用します。撮影、文字矩形、下線・塗りの描画を同じ境界に制限し、手前に重なる別ウィンドウも除外します。非同期認識後にウィンドウ・要素・範囲を再確認し、古い結果を破棄します。UIAから対象領域を取得できない場所ではOCRを実行せず表示を消します。

ポインタが約65ミリ秒静止すると認識し、UIAは通常約180ミリ秒ごとに更新します。OCRは画像サイズ・PC性能によりさらに遅くなります。行末の空白や行間では表示を消します。短いタブ見出しや、文字の途中で分割されたUIA要素では認識できなかったり、一部の範囲だけを表示したりすることがあります。

## 制約とデータの扱い

画像・本文のファイル保存、外部送信、ネットワーク通信、テレメトリ、自動起動、権限昇格は実装していません。OCR画像はメモリ上に短時間保持します。機密情報の表示中は常時表示を一時停止し、「Ctrl押下で実行」もオフにしてください。UIAがパスワード欄と判別できる場所では認識を停止しますが、独自描画の機密欄をすべて判別できるわけではありません。

下線・塗りは入力を透過し、フォーカスを奪わない最前面ウィンドウです。Windows 10 2004以降ではOCR撮影中だけ強調表示をキャプチャから除外し、その後に戻します。非対応環境では一時非表示とし、ログに「互換モード」を表示します。画面共有では画面全体の共有を使用してください。アプリ単体のウィンドウ共有には強調表示が含まれないことがあります。

縦書き、回転文字、極小文字、複雑な背景、特殊なPDFや独自UIには認識の限界があります。モニターをまたぐ行はポインタ側のモニター内に制限します。透過・不定形の前面ウィンドウも矩形として除外するため、認識範囲が狭くなる場合があります。排他的フルスクリーン、保護映像、ロック画面、UAC画面、管理者権限アプリなどでは利用できないことがあります。

.NETランタイムは同梱しています。OCRのネイティブDLLにはMicrosoft Visual C++ 2015–2022 x64 Redistributableが必要です。アプリは自動インストールしません。実行ファイルは未署名です。

## ビルドと資料

`source` フォルダーで.NET 8 SDKとPowerShell 7（pwsh）を使用します。`Build.ps1` は自動テストとビルドを実行します。

```powershell
./Build.ps1
```

リポジトリルートから見た出力は `source/out/LiveTextMarker/LiveTextMarker.exe` です。ビルドのみを行う場合は、`source` フォルダーで次を実行します。

```powershell
dotnet publish LiveTextMarker.csproj -c Release -r win-x64 --self-contained true -p:Platform=x64 -o out/LiveTextMarker
```

ビルド時のみ依存パッケージ等を取得し、実行時はオフラインです。作業フォルダーは `C:/develop/test/LiveTextMarker`、プロジェクトは `source/LiveTextMarker.csproj`、内部名前空間とMutexもLiveTextMarkerです。設定は `%LOCALAPPDATA%/LiveTextMarker/settings.json` に保存します。新保存先に読み込める設定がない場合は、旧保存先 `%LOCALAPPDATA%/PointerUnderline/settings.json` から自動で引き継ぎます。旧設定は削除しません。
