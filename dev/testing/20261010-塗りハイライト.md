# 塗りハイライトの追加

- 下線／塗りを表示方法から切り替える。折り返しの各表示行を薄く塗る。
- 初期色は黄色、濃さ16%。元の文字・背景を84%残す半透明合成を使用し、不透明度を8～30%に制限する。
- 下線の色と塗りの色を別々に保持する。塗りの色・濃さ・表示方法も設定保存する。
- 塗りでは太さ・上下位置を無効化し、文字範囲そのものを覆う。余分な縦の余白を加えず行同士の二重合成を避ける。
- 描画ウィンドウの入力を無効化し、クリック透過・フォーカス保持・OCR撮影時の点滅対策を維持する。

## 検証

- [x] 自動テスト30件成功。自己完結型win-x64 Releaseビルド成功。
- [x] 白背景・暗い背景で黒文字・白文字・色付きリンクが透けて読めることを画像で確認。3行の高さ42pxと実際のアルファ値41/255（約16%）を確認。下線へ戻すと高さ3px・アルファ255。
- [x] Ctrl解除で消去、空白へ移動して消去、文章へ復帰して再表示。UIA/OCRの6秒測定で表示・非表示イベント、前景変更、消失サンプルすべて0。
- [x] 再起動後の塗り・濃さ16%の保持を確認。配備版PID 42396が正常応答。塗り・Ctrlモードの開始済み状態で残す。

## 追加の調整

塗りを重ねた状態のOCR試験で隣接アプリの文章を含む判定が生じたため、OCR撮影範囲をDWMの対象ウィンドウ表示範囲とモニター内へ制限した。撮影からの除外はCopyFromScreenの瞬間だけ行い、PNG圧縮前に通常キャプチャへ復元する。旧設定ファイルに新しい項目がなくても、下線モード・黄色・16%として読み込める。
