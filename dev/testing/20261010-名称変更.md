# LiveTextMarkerへの名称変更（2026-10-10）

> 現行仕様への参照：この資料は作業当時の記録です。最新の名称・操作・仕様は [LiveTextMarker仕様書](../../docs/仕様.md) を参照してください。

- アプリ名をLiveTextMarkerへ変更した。画面タイトル、通知領域、重複起動メッセージ、実行ファイル名、製品情報、ビルド出力先、READMEと実行用検証スクリプトの参照先を更新した。
- 実行ファイルは `app/LiveTextMarker.exe`。作業フォルダ名、内部名前空間、csproj名は既存のまま維持した。
- 保存済み設定と旧版との二重起動防止の互換性のため、設定保存先とMutex名を維持した。
- 新名称でビルドし、旧版を通常終了した後に配備・再起動済み。旧名のアプリ実行ファイル・関連するアセンブリファイルは配備先から除去した。
- ユーザーの「テスト不要」の指示により追加のテストは行わない。指示より前に自動テスト47件とビルドが成功し、動作確認を実行していた。
