# Ctrl独立実行と下線の太さ安定化（2026-10-10）

## 要求と変更

- [x] Ctrl押下で実行する機能を開始・一時停止と独立させる。
  - 動作条件を「開始状態 OR（Ctrl押下を有効にした状態 AND Ctrl押下中）」とした。
  - Ctrl+Alt+Uと開始ボタンは常時表示の状態だけ切り替える。一時停止中でもCtrl押下で表示する。常時表示中はCtrlを離しても表示を続ける。
  - チェック欄を「Ctrl押下で実行」とし、開始・停止にかかわらず待機状態を表示する。
- [x] 行によって下線の太さが異なる原因を調査・修正する。
  - 文字要素の下端と重なる下線を単純にIntersectで切り取っていたため、末尾行などが細くなっていた。
  - DPI換算した太さを整数ピクセルへ丸め、全ての行で同じ高さを使用する。境界付近では高さを削らず、線を上下へ移動して全体を範囲内へ収める。
  - 境界が線の高さより狭い場合は表示しない。上下位置の設定は境界内に収まる範囲で適用する。
