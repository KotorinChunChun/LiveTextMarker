# 本アプリの対象除外と文字付近の判定（2026-10-10）

## 切り分け

ユーザーからC#アプリが取得できない疑いが示されたが、続いて他のC#アプリは検知できており、文字付近の判定が厳しかったとの補足があった。C#アプリ全般の障害とは扱わない。

本アプリの標準コントロールをUIAで読み取り、ラベル・ボタン・チェックボックスの要素とNameは取得できるが、TextPatternを提供しないことを確認した。数値入力内のEditはTextPatternを提供していた。本文・入力値は記録しない。

## 変更

- [x] Controllerが同一プロセスを一律除外していた処理を削除し、描画用オーバーレイだけを除外した。本アプリの設定画面も認識対象となる。
- [x] 文字付近の許容幅を固定2ピクセルから行の高さの25%（3～6ピクセル）に変更した。文字矩形内を優先し、同じ条件を候補選択・非同期結果の採用・表示維持に使用する。
- [x] ウィンドウ・要素の境界と重なりの制限は広げない。描画範囲も拡大しない。
- [x] CheckBox、RadioButton、ComboBox、Spinnerを最寄りの認識境界として追加した。
- [x] OCRを使う場合のログを「UIA要素取得・TextPatternなし」と「UIA文字範囲なし」に分けた。NameやValueだけから文字の行矩形を推測してUIA認識成功とは扱わない。
- [x] Releaseビルド成功、配備版を更新して再起動済み。ユーザーの指定に従いテストは実行しない。修正後の文字追従・本アプリ上の表示は実測していない。
