# タブ見出しの境界制限（2026-10-10）

## 原因と変更

認識境界のControlType一覧にTabItemとTabが含まれていなかった。タブ見出しのUIA要素がTextPatternを持たない場合、親Paneなどの広い矩形でOCRと描画を制限していたため、隣接見出しまで範囲が広がり得た。

- [x] 個々のTabItemとTabコンテナを境界一覧に追加した。最寄りのTabItemを先に採用するため、OCR画像・認識結果・描画が隣接タブへ伸びない。
- [x] 検証用画面と実機テストを追加した。
- [x] 40件の自動テストとReleaseビルドが成功した。
- [x] 配備版を更新・通常終了後に再起動し、下線表示・Ctrl待機中とした。

## 実測

`タブ境界検証.ps1 -Live` で「音声／認識比較／操作／操作履歴／技／ナレッジ／設定」の7個のWinForms TabItemを取得した。各認識領域が対応するTabItemの矩形内に収まった。下線と塗りを順に7個ずつ測定し、隣接タブ・本文への描画は0件だった。14組合せ中8組合せで表示できた。

最初の描画試験は、起動直後の設定画面の準備前にComboBoxを取得したためテスト側で停止した。対象画面の表示を待つ手順へ修正して再実施し成功した。

## 確認範囲と制約

添付画像と同じタブ名・隣接構成を持つ専用画面で検証した。添付の実アプリそのものの再測定ではない。小さなタブ見出しはOCRが認識できないことがある。その際は表示せず、親全体へ認識領域を広げない。
