# ウィンドウ・フレームの境界を越える認識の修正

## 方針

- UI Automationでポインター配下の文書・編集欄・ペイン・表など最寄りのフレーム領域と識別子を取得し、UIAの文字矩形とOCR画像を同じ領域へ制限する。
- 広い親のTextPatternへ置き換えず、最初の有効な文字範囲を使用する。
- 他ウィンドウで隠れた部分をZ順序から除外し、ポインターを含む安全な矩形だけ撮影・描画する。
- 非同期認識後にフレーム識別子と領域を再取得し、変化した結果を破棄する。対象領域を取得できない場合は全画面OCRへ戻さず表示を消す。
- 描画時にも領域でクリップし、認識後のウィンドウ重なり変更も再確認する。

## 検証

- [ ] 領域クリップ、重なり除外の自動テストとビルド。
- [ ] 同じウィンドウ内の隣接フレームでUIAとOCRを検証。
- [ ] 別ウィンドウの重なり、境界での描画制限を検証。
- [ ] 既存の複数行・Ctrl・塗り・点滅の回帰確認と配備版の再起動。
