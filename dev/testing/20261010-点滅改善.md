# 下線の点滅とアクティブウィンドウ切り替わりの改善

## 調査と方針

- 下線更新で Form.Bounds・Show・Hide とネイティブ SetWindowPos が混在していた。位置変更・表示・非表示を SWP_NOACTIVATE 付きのネイティブ操作に統一し、同じ範囲の再表示を省く。
- OCR撮影前に毎回 HideLines を呼んでいたため、撮影頻度に応じて下線が一時的に消える経路が存在した。
- Windows 10 2004以降では、OCR撮影の同期処理中だけ下線をキャプチャから除外し、画面上では表示を維持する。finallyで通常のキャプチャ可へ戻す。永続的に画面共有から除外しない。
- 除外APIが利用できない場合だけ従来の一時非表示へ戻し、画面ログに互換モードを表示する。
- ユーザーの対象アプリ上での現象と、検証画面での実測を区別する。

## 検証

- [ ] ビルド・既存自動テスト。

- [ ] Ctrl解除、停止、移動後の再表示、設定保持の回帰確認。
- [ ] 検証済み配備版を再起動し、結果を記録する。
