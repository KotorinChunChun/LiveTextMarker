# 文章認識と操作・表示の改善

> 現行仕様への参照：この資料は作業当時の記録です。最新の名称・操作・仕様は [LiveTextMarker仕様書](../../docs/仕様.md) を参照してください。

## 要求と実装方針

- 折り返しを含む文章について、各表示行の行頭から行末まで下線を引く。UI Automation の段落範囲を優先し、文字断片を行単位で結合する。
- OCR では段落内の複数行をまとめて取得する。列・段落が異なる文字を安易につながない。
- Ctrl を押している間だけ表示するモードを追加する。キーを離した時と停止時には、非同期認識結果も破棄する。
- 初期の上下位置を上げ、負の値と小数による調整を可能にする。設定は再起動後も維持する。
- 最新の検出方式と直近10件のログを画面に表示する。本文・画像はログに記録しない。

## 再現手順

PowerShell 7で次を実行する。操作検証は実際のカーソル・Ctrlキーを使うため、実行中はPCの操作を控える。検証画面は終了し、利用するアプリは起動したままにする。

```powershell
cd C:\develop\test\PointerUnderline
dotnet run --project source/tests/GeometryTests.csproj -c Release
pwsh -NoProfile -File dev/testing/認識検証.ps1
# app/PointerUnderline.exe を起動してから実行
pwsh -NoProfile -File dev/testing/操作検証.ps1
```

## 制約

UI Automation が段落範囲を正しく公開しないアプリや、OCR が段落を分割してしまう画像では文章全体の判定に限界がある。検出方式と行数を画面で確認できるようにする。
